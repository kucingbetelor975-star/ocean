📋 LANGKAH-LANGKAH:

1️⃣  UPLOAD MODEL KE GOOGLE DRIVE (2 menit)
   
   a. Buka https://drive.google.com
   
   b. Klik tombol "+ New" → "File upload"
   
   c. Pilih file: model/model_air.h5 (145 MB)
   
   d. Tunggu upload selesai

2️⃣  DAPATKAN DIRECT DOWNLOAD LINK (1 menit)
   
   a. Klik kanan file model_air.h5 → "Share"
   
   b. Klik "Change to anyone with the link"
   
   c. Copy link yang muncul, contoh:
      https://drive.google.com/file/d/1AbC123XyZ_CONTOH_ID/view
   
   d. AMBIL BAGIAN FILE_ID (antara /d/ dan /view)
      Contoh: 1AbC123XyZ_CONTOH_ID
   
   e. Buat direct download link dengan format:
      https://drive.google.com/uc?export=download&id=FILE_ID&confirm=t
      
      Contoh lengkap:
      https://drive.google.com/uc?export=download&id=1AbC123XyZ_CONTOH_ID&confirm=t

3️⃣  SET ENVIRONMENT VARIABLE DI RAILWAY (1 menit)
   
   a. Buka dashboard Railway: https://railway.app/dashboard
   
   b. Pilih project "ocean" atau "OceanAI"
   
   c. Klik tab "Variables"
   
   d. Klik tombol "+ New Variable"
   
   e. Isi:
      Variable name: MODEL_URL
      Value: [paste direct download link dari langkah 2e]
   
   f. Klik "Add"

4️⃣  REDEPLOY APLIKASI (1 menit)
   
   a. Masih di Railway dashboard
   
   b. Klik tab "Deployments"
   
   c. Klik "Deploy" atau Railway akan auto-deploy
   
   d. Tunggu build selesai (3-5 menit)
   
   e. Cek logs untuk memastikan model ter-download:
      ✅ Cari pesan: "Model berhasil diunduh dari MODEL_URL!"
      ✅ Atau: "Model sudah ada: model/model_air.h5"

5️⃣  TEST APLIKASI (30 detik)
   
   a. Buka URL Railway Anda (contoh: https://ocean-xxx.railway.app)
   
   b. Pergi ke halaman "Analisis"
   
   c. Upload gambar air
   
   d. Jika hasil prediksi muncul → ✅ BERHASIL!

═══════════════════════════════════════════════════════════════════════

🎯 RINGKASAN SUPER CEPAT:

1. Upload model_air.h5 ke Google Drive
2. Share → Dapatkan FILE_ID
3. Buat link: https://drive.google.com/uc?export=download&id=FILE_ID&confirm=t
4. Railway → Variables → MODEL_URL = [link tadi]
5. Redeploy → DONE! ✅

═══════════════════════════════════════════════════════════════════════

❓ TROUBLESHOOTING:

Q: Download dari Google Drive gagal (Error 403)?
A: Pastikan file di-share sebagai "Anyone with the link" dan 
   tambahkan &confirm=t di akhir URL

Q: Model tetap tidak ditemukan setelah deploy?
A: Cek Railway logs → Deployments → View Logs
   Cari error message untuk diagnosis

Q: Aplikasi error saat startup?
A: Pastikan environment variable MODEL_URL sudah diset dengan benar
